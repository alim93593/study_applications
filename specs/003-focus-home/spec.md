# Spec 003 — شاشة الفوكس (Home) ببيانات حقيقية

## الهدف
إحلال القيم الوهمية في شاشة الفوكس (Home tab) ببيانات Firebase،
وإعطاء الكويك أكشن معنى حقيقيًا بدل أزرار ميتة (quiz/leaderboard غير موجودين).

## القرارات المعتمدة من المستخدم
1. بطاقات الإحصائيات: **مهام اليوم / ساعات تركيز اليوم / نسبة الإنجاز**
   — تُحذف "النقاط" (points) لعدم وجود مصدر بيانات.
2. الكويك أكشن: مهمة جديدة (صفحة NewTask) + المهام + الجدول + الإحصائيات
   (تبويبات الشيل) — quiz وleaderboard يُشalan لعدم وجود ميزة.

## المتطلبات
- **FR-H01**: `HomeCubit` يشتغل على مهام (`TasksRepository.watchTasks`)
  وجلسات (`StatsRepository.watchSessions`) ويعيد الحساب مع كل تحديث.
- **FR-H02**: مهام اليوم = مهام (غير مسودة) dueDate = اليوم. تركيز اليوم =
  مجموع دقائق جلسات اليوم / 60. نسبة الإنجاز = completed / (غير مسودة) %.
- **FR-H03**: `HomeStatsRow` يعرض الحالة عبر `BlocSelector` (صفر منطق UI).
- **FR-H04**: الكويك أكشن يتنقل: `push(newTask)` / `shell args 1..3`.
- **FR-H05**: قواعد المشروع: Cubit فقط، BlocSelector إلزامي، ≤ 100 سطر،
  مفاتيح ترجمة عبر `HomeStrings` ثوابت.

## خارج النطاق
تغيير شكل البطاقات أو الترحيب — البناء الحالي يبقى كما هو.
