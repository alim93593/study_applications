# Spec 004 — حذف وتعديل المهام من الواجهة

## الهدف
إتاحة حذف وتعديل المهمة من شاشة المهام. طبقة الداتا جاهزة
(`TasksRepository.updateTask/deleteTask` متوصلين بـ Firestore) —
المفقود واجهة فقط.

## القرارات
1. **الحذف**: سحب البطاقة لليسار (Dismissible) + تأكيد قبل الحذف
   + snackbar نجاح/فشل.
2. **التعديل**: ضغط على جسم البطاقة → صفحة NewTask بوضع تعديل
   (تعبئة مسبقًا + زر "حفظ التغييرات" + إخفاء "حفظ كمسودة").
3. **المؤرشفة** = تبويب المكتملة (بدون تغيير — إجابة للمستخدم).

## المتطلبات
- **FR-T01**: swipe يفتح تأكيد؛ التأكيد يستدعي `deleteTask(id)`؛
  النجاح → snackbar `task_deleted`، الفشل → snackbar الخطأ الحالي.
- **FR-T02**: ضغط البطاقة يفتح `NewTaskPage(task)` — Cubit يعبّئ
  الحقول و`submit` يستدعي `updateTask` مع الحفاظ على id/createdAt.
- **FR-T03**: في وضع التعديل: العنوان "تعديل مهمة"، الزر الأساسي
  "حفظ التغييرات"، وزر المسودة مخفي، حالة المكتملة تبقى مكتملة.
- **FR-T04**: قواعد المشروع: Cubit فقط، BlocSelector، ≤ 100 سطر،
  مفاتيح عبر ثوابت + ar/en، try-catch في الـ Repository فقط.

## خارج النطاق
إعادة ترتيب المهام، الأرشيف كـ status منفصل.
