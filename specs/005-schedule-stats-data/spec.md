# Spec 005 — بيانات الجدول والإحصائيات الحقيقية

## المشكلة
- الجدول يقرأ `users/{uid}/schedule` — **لا يوجد أي كود يكتب فيه** → فارغ دائمًا.
- الإحصائيات تقرأ `users/{uid}/sessions` — **لا يوجد سجّل جلسات** → أرقام 0 دائمًا.

## القرارات
1. **الجدول يُبنى من المهام** (مصدر واحد للحقيقة): مهام اليوم +
   المتأخرة (pending) + ما أُنجز اليوم. يُحذف طبقة schedule الميتة.
2. **مؤشر جلسات التركيز**: بطاقة على شاشة الفوكس — اختيار مادة +
   مؤقت يعمل (start/stop) → يكتب `StudySession{subject, minutes, date}`
   في `sessions` → الإحصائيات والوقت اليومي يُضاءان فورًا (ستريم حي).
3. خط ميتاداتا الكارد (meta) أوضح + placeholders `{0}` → `{}` (تم).

## المتطلبات
- **FR-S05**: ScheduleCubit يستمع لـ TasksRepository ويعرض المناسب
  لليوم؛ progress = نسبة المنجز.
- **FR-S06**: `addSession` عبر DataSource (صفر try-catch) + Repository
  (فحص نت + Either) + DI.
- **FR-S07**: `FocusSessionCubit`: start/stop، مؤقت يدق كل ثانية،
  الدقائق المحسوبة تُحفظ؛ ≤ 100 سطر لكل ملف.
- **FR-S08**: قواعد المشروع كاملة (Cubit، BlocSelector، مفاتيح، ≤100).
